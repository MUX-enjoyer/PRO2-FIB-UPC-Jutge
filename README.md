# PRO2 FIB UPC: solucions dels exercicis del Jutge en C++

Solucions comentades dels exercicis del [Jutge](https://jutge.org) de l'assignatura **Programació 2 (PRO2)** de la **FIB (UPC)**, en C++: piles i cues, iteradors i llistes, diccionaris i conjunts (`map`, `set`), arbres binaris i generals, disseny modular, classes `Stack`, `Queue`, `List` i `BinTree`, exàmens resolts i les pràctiques.

*Soluciones de los problemas del Jutge de PRO2 (FIB-UPC) en C++ · Jutge.org PRO2 problem solutions in C++.*

Cada fitxer es diu `ID Títol.cc`, amb l'identificador del problema al Jutge, perquè el pugueu trobar fàcilment.

### Pràctiques
- **Mario PRO2** (🌸): carpeta `PRÀCTICA MARIO-PRO2`, amb les diferents parts i versions d'eficiència.
- **Encriptació de missatges** (🍂): carpeta `PRÀCTICA ENCRIPTACIÓ 2026`, amb l'enunciat (`ENUNCIAT/`) i la implementació de la fase 2 fins abans de l'encriptació (afegir, esborrar i llistar missatges i alfabets). Es compila amb `make` i es prova amb `./program.exe < sample.inp` (el `sample.inp` i el `sample.cor` són dins `ENUNCIAT/practica.zip`).
